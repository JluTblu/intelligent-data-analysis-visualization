# Словарь полей основного учебного датасета курса (iavd_ml_dataset)

Учебный датасет `iavd_ml_dataset.parquet` (схема выгрузки 2.5 SOAR) для
треков **BI-аналитики** и **ML-инжиниринга** курса «Интеллектуальный анализ и визуализация данных». Основной датасет курса: 94-колоночная схема карточек инцидентов SOC.

Каждая инцидент-карточка - зарегистрированное событие (алерт), сгруппированное системой корреляции в инцидент/атаку для обработки дежурным аналитиком SOC. Одна строка = одна карточка (обычно группа однотипных алертов).

## 5. Флаги рабочего процесса (workflow) - категория C

`Спам`, `Эскалировался на L2?`, `Пауза`, `На мониторинг`, `Заблокировать`,
`SLA просрочен (взятие в работу)`, `Проверка на FP выполнена`,
`Выполнено первичное сдерживание`, `Обогащение выполнено`,
`Классификация выполнена`, `Успех brute force`, `False Positive` (**прямой
дубликат таргета**), `Легитимность действия`, `Открыт для редактирования`,
`Белый список`, `Ложное срабатывание` (**дубликат таргета**),
`Инцидент был изменен` - булевы признаки процесса обработки; ставятся в
ходе расследования. *BI*: воронка процесса. *ML*: **исключить из признаков**
(утечка цели). Тип - str: `true` / `false` / NaN.

## 6. Спец-формы: JSON-структура ответственных

«Ответственный» и «Прошлый ответственный» хранят ФИО структурой:

```json
{"lastName": "Цветков", "firstName": "Даниил", "middleName": "Денисович "}
```

Разбор (ML): `json.loads(v)` -> словарь; все имена фиктивные.

## 7. Мультизначные поля: JSON-массивы (главное отличие от 1.5!)

В 2.5 списки хранятся **JSON-массивами** (разделитель `~~||~~` не используется).
Внутри элементов пары «ключ|значение» сохранены. В строках parquet
внутренние кавычки удвоены и слэши экранированы: `"C:\\\\Users\\\\..."`.

Пример (FilePath): `["C:\\Users\\bolshakov-a\\Desktop\\", "C:\\Temp\\"]`

**Разбор (ML, pandas):**

```python
import json
arr = json.loads(v.replace('\\\\\\\\', '\\\\'))   # снять двойное экранирование
# элементы: строка или пара «ключ|значение»
items = [x.split('|', 1) for x in arr]
```

Производные признаки: `len(arr)` - число элементов; `set(...)` - уникальные
значения; для пар - роль (src/dst) отдельным столбцом; для текстов -
объединение через `'; '.join(arr)`.

**Разбор (BI, Qlik):** JSON-массив не разворачивается SubField -
используйте разбор по кавычкам (`SubField(Mid(...), '"')`) или
предобработку в pandas перед загрузкой (рекомендация курса для
мультизначных полей).

## 8. Предупреждения

1. **Даты и числа - строки ISO/str**: парсить `pd.to_datetime(...)` /
`pd.to_numeric(..., errors='coerce')`; «Время решения» содержит
экстремальные выбросы (медиана ~36 ч, максимум - сотни млн часов) -
сначала диагностика, потом агрегаты.
2. Метки времени ранее 12.04.2024 - выбросы (см. Сводку).
3. «Вердикт» содержит NaN (не размечено) - метрики качества считать
только по размеченным строкам (см. про `Flag_ValidLabel` на лекции 3.1).
4. `EntityId` - ключ соединения; в логе инференса практики 3.6 он же
`incident_id`.
5. Не включайте поля категории C в признаки: модель покажет
нереалистичное качество (учебная «ловушка утечки» - см. раздел «Категории полей»).

## 9. Фичеринжиниринг в полном цикле приложения

Для проектов полный цикл разработки приложения: фичеринжиниринг -> BI/ML ->
интерактивное приложение:

1. **Целевая:** y = 1 «Решён» / 0 «False Positive»; прочие вердикты
(Дубликат, SPAM, Не решён, Закрыт..., NaN) исключить (~197 746
размеченных строк, дисбаланс ~5,5:1).
2. **Производные времени (A):** час, день недели, месяц от «Создан»;
длительность «последнее - первое событие»; задержка SIEM->SOAR.
3. **Мультизначные (A):** длины массивов (число команд, файлов, учеток),
счетчики уникальных значений, флаги присутствия (есть ли regsvr32,
powershell, обфускация).
4. **Категориальные (A):** Наименование/Правило SIEM (группировка редких),
Критичность, Пиктограмма IRP, category*, suser/duser/Hostname
(высокая кардинальность - частотное кодирование или хэш).
**Обучение собственной модели - по желанию** (например, RandomForest, CatBoost, LightGBM): курс сфокусирован на анализе и визуализации результатов. При самостоятельном обучении обязательно соблюдение категорий полей A/B/C.

5. **Текстовые (A):** CMDLINE/Команда - маркеры флагов (`/s`, `-enc`,
`downloadstring`), длина, токены; Алерт/Описание - словарные признаки.
